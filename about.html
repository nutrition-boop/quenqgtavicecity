About QUENQQ

What is QUENQQ?

QUENQQ is a free browser gaming platform that brings classic open-world games directly to your web browser using cutting-edge WebAssembly (WASM) technology. No downloads. No installs. No accounts. Just open the page and play.

Our flagship title is Quenq GTA Vice City — a fully playable, in-browser port of the legendary 2002 Rockstar Games classic, powered by the open-source reVC reverse-engineering project. The entire game engine runs inside Chrome, Edge, Firefox, or Safari using WebGL 2.0 and WebAssembly, with no plugins or extensions required.

Our Mission

We believe great games should be accessible to everyone — regardless of their hardware, operating system, or technical skill. A 15-year-old gaming PC shouldn't be required to relive a 2002 classic. QUENQQ is built on the conviction that preserving gaming history means making it playable, not just archivable.

We also believe your data belongs to you. That is why all game save files are stored locally in your browser's IndexedDB — never on our servers. We have no user accounts, no cloud saves, and no personal data collection tied to gameplay.

How the Technology Works

The QUENQQ game engine is built on top of the community-developed reVC project — an open-source, clean-room reverse-engineered recreation of the GTA Vice City game engine. The C++ engine is compiled to WebAssembly using Emscripten, enabling it to run at near-native speeds inside any modern browser.

Graphics are rendered via WebGL 2.0, audio is handled through the Web Audio API, and game saves use browser-native IndexedDB — giving you up to 8 independent save slots that persist between sessions. Input is handled via the Gamepad API for controller support, and custom on-screen touch joysticks for mobile play.

The game data (~120 MB) loads once and is cached locally using the browser's cache storage — meaning subsequent visits load almost instantly without re-downloading anything.

What We Offer

  • Full game experience: All story missions, side missions, hidden packages, and properties.
  • 8 save slots: Browser-local IndexedDB saves — no account needed.
  • Gamepad support: Xbox, PlayStation, and any USB/Bluetooth controller via the Web Gamepad API.
  • Mobile touch controls: Dual joysticks, HUD buttons for driving, shooting, and cheats.
  • All cheat codes: Every original PC cheat code works identically in the browser.
  • All radio stations: Flash FM, V-Rock, Wave 103, Emotion 98.3, and more — full 80s soundtrack.
  • Free, forever: No subscriptions, no ads on the game, no paywalls.
